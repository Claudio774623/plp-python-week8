# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that combines three simple tools into one menu-driven application. The toolkit contains a Number Guessing Game, a To-Do List, and a Simple Calculator. The program uses variables, input and output, conditionals, loops, lists, functions, and f-strings.

## Tools Included

### 1. Number Guessing Game

The Number Guessing Game allows the user to guess a secret number between 1 and 10. The program gives feedback when the guess is too high or too low and continues until the correct number is guessed.

### 2. To-Do List

The To-Do List allows the user to add tasks, view tasks, and remove tasks. The tasks are stored in a Python list that changes while the program is running.

### 3. Simple Calculator

The Simple Calculator allows the user to perform addition, subtraction, multiplication, and division.

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python toolkit.py
```

6. Choose a number from the menu to use one of the tools.
7. Choose option 4 when you want to quit.

## Reflection

The hardest part of this project was combining different Python concepts into one program that works through a menu. The menu loop required careful thinking because it needed to continue running after each tool finished. One bug that took time to fix was making sure invalid user input did not cause the program to crash. I learned that error messages can help identify where a problem exists in the code. Building the To-Do List also helped me understand how lists can change while a program is running. The project helped me become more confident with loops, conditionals, functions, and user input. If I had one more week, I would add more tools and improve the design of the program.
